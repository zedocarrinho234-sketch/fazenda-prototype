# Fazenda Prototype

Este repositório contém o protótipo da sua fazenda (HTML/CSS/JS).

O arquivo principal já está no repo: `index.html`.

O que falta (passos finais):

1. Adicionar a imagem de cenário (`farm.jpg`) na raiz do repositório. Use a versão em alta resolução para melhores recortes e visual.
2. Ajustar as posições dos hotspots (se necessário). Use a ferramenta `hotspot-editor.html` que eu adicionei — ela gera as porcentagens (left/top/width/height) para colar diretamente em `index.html`.
3. Testar localmente: faça download do ZIP (Code → Download ZIP) ou clone o repo e abra `index.html` no navegador.

Como finalizar para publicação:

- Se quiser que eu remova a chave PIX pública do arquivo antes de publicar, me diga “remover PIX”.
- Para gerar o ZIP pronto: você pode usar Code → Download ZIP na interface do GitHub ou eu posso gerar instruções/scripts para zipar via terminal.

Suporte adicional:
- Posso recortar sprites a partir da sua imagem e substituí‑los no protótipo — envie a imagem em alta ou confirme que eu posso usar a que já está no repo.

------

Por enquanto, o repo contém também a ferramenta `hotspot-editor.html` para ajustar visualmente as áreas clicáveis (hotspots). Abra-a localmente para carregar sua imagem e arrastar os retângulos.
